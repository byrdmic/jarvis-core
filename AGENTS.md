Use `bun run src/server.ts` to start the server.

Keep reading the logs as you spin things up until you know it works.

To stop the server, use `Ctrl+C`. It's very important to stop the server when you're done with it. Don't leave it running in the background. If that doesn't work, use `lsof -i :4000` to find the process id and kill it with kill <process id>.
